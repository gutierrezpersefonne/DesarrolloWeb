Introducción al Desarrollo Web

Bienvenidos al curso de Introducción al Desarrollo Web. En este espacio conoceremos los fundamentos de la creación de páginas web, su funcionamiento, sus principales tipos y los elementos que permiten presentar información a través de Internet. El objetivo es comprender cómo se estructura una página web utilizando HTML y reconocer su importancia en la comunicación, la educación y el acceso a la información.

¿Qué es una página web?

Una página web es un documento digital que puede visualizarse mediante un navegador web y al que se accede normalmente a través de Internet. Puede contener texto, imágenes, enlaces, videos, audios y otros elementos que permiten presentar información de manera organizada. HTML (HyperText Markup Language) es el lenguaje de marcado utilizado para definir la estructura y el contenido de una página web.

¿Cómo funciona una página web?

Cuando una persona escribe una dirección web o selecciona un enlace, el navegador solicita los recursos necesarios al servidor donde se encuentra alojada la página. El servidor responde con los archivos correspondientes y el navegador interpreta el contenido para mostrarlo al usuario.

En este proceso, HTML organiza el contenido de la página. Otros recursos, como las hojas de estilo y los lenguajes de programación, pueden utilizarse para modificar su presentación o incorporar funciones interactivas. Sin embargo, para esta asignación se utilizará únicamente HTML.

Tipos de páginas web

Páginas web estáticas

Una página web estática presenta contenido que permanece esencialmente igual para los visitantes, salvo que sus archivos sean modificados. Su información suele estar escrita directamente en documentos HTML y puede consultarse sin necesidad de generar contenido diferente para cada solicitud. Un ejemplo es una página informativa que presenta la historia y los datos de una institución.

Páginas web dinámicas

Una página web dinámica puede generar o actualizar su contenido según las acciones del usuario, los datos disponibles o la información solicitada. Para ello, normalmente utiliza programación y, en muchos casos, comunicación con un servidor o una base de datos. Algunos ejemplos son las plataformas educativas que muestran las calificaciones de cada estudiante y los sitios de comercio electrónico que actualizan sus productos y carritos de compra.

Diferencia entre un sitio web y una aplicación web

Sitio web

Un sitio web es un conjunto de páginas web relacionadas entre sí que se encuentran bajo un mismo dominio y presentan información sobre un tema, una organización, un servicio u otra finalidad. Por ejemplo, un sitio web institucional puede incluir páginas sobre la universidad, sus carreras, sus autoridades y sus datos de contacto.

Aplicación web

Una aplicación web es un sistema al que se accede mediante un navegador y que permite realizar operaciones o interactuar con funciones específicas. Puede procesar información, recibir datos del usuario y ofrecer resultados personalizados. Algunos ejemplos son una plataforma de banca en línea, un sistema de inscripción universitaria o una aplicación para gestionar tareas.

La diferencia principal está en su propósito y funcionalidad: un sitio web suele centrarse en presentar información, mientras que una aplicación web está orientada a permitir que el usuario realice tareas mediante sus funciones. Ambos conceptos pueden superponerse, ya que un mismo sitio puede incorporar funcionalidades propias de una aplicación web.

Elementos multimedia del desarrollo web

Las páginas web pueden incorporar diferentes recursos multimedia para complementar la información, facilitar la comprensión de los contenidos y ofrecer una experiencia más completa al visitante.
